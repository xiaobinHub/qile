## 规范与实现

官网来源：https://ui.shadcn.com/init?preset=b2C8W74qG 。原始配置保存在 `shared-ui/preset.json`。采用 Maia、Mist、黄色主色、Inter Variable、Lucide；浅色和深色原始变量完整保留，当前页面继续使用浅色模式。

家长端和后台共用 `shared-ui/src/theme.css` 及组件。按钮、输入框、卡片、菜单、选择器、确认弹窗、抽屉、标签和切换控件应用官方 Maia 源码与形状；登录、日历、商城、孩子卡牌、设置及后台使用相同语义变量，保留现有布局和业务交互。任务类型颜色与成功、警告、危险状态各自保留含义。打印专用 CSS 块与改造前一致。

预设默认是 Base UI 的 `base-maia`。为兼容已验证的 Radix 焦点、事件及业务集成，此次使用官方相同 Maia 风格的 `radix-maia`，三份 `components.json` 明确记录该适配；未将运行时替换为 Base UI。组件来源与文件 SHA-256 见 `shared-ui/registry-provenance.json`。Calendar 保留中文、周一开周和本地日期处理，使用同一圆润视觉。

正文中的品牌文字使用棕色 `brand-ink`，黄色配棕字用于品牌按钮。官网灰字在浅灰底上只有约 4.13:1，因此增加 `text-secondary`；危险按钮悬停时使用较深的 `destructive-ink`（约 4.85:1）。原始预设 token 不改写。

Inter 以本地 WOFF2 打包，中文使用系统字体回退。字体许可证随项目保留。服务只从各端构建目录提供字体，未引入 CDN 或放宽私有文件限制。没有新增数据库迁移、API 业务变化或数据迁移。
