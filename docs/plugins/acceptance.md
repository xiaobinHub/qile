# 插件平台本地验收记录

日期：2026-10-31（北京时间）。分支：`codex/plugin-mode`。

本次交付为本地功能实现和隔离验收，没有发布生产。平台级删除已按用户要求排除；家长卸载保留配置和历史记录。

## 已实现

- 儿童级共享安装、启停、配置和菜单，家庭负责人管理。
- 页面型插件按需加载顶部页面，后台型插件使用通用配置弹窗，无顶部入口。
- 管理后台资料、包内图标选择、待发布/已上架/已下架、全量/指定儿童范围。
- 独立插件目录、清单和前后端协议、不可变制品及资源校验。
- 独立 Python 工作进程和私有 Unix 服务、状态围栏、记录命名空间、定时任务与事件投递。
- 单插件准备/更新/排空/切换/恢复，失败回退及中断恢复，主系统继续运行。
- 两个参考插件：成长随记、提醒执行示例。提醒示例只产生执行记录，不发送外部消息。

## 实机和发布边界

Linux systemd 服务模板、资源限制及真实生产连接仍需首次部署时验收。本地独立进程测试在 macOS 执行；未把这些结果记成 Linux 实机通过。

首期独立更新接受无需转换的配置/数据格式；不兼容转换拒绝进入在线更新流程。外部通知渠道和凭据存储不在参考插件交付范围内。正式上线前，先对实际目标显式执行插件表升级、配置运行目录和服务，再部署插件并由管理员上架。

## 本地开发环境衔接

2026-10-31 现场检查发现开发服务仍为 10 月 29 日启动的旧进程，而页面已更新，导致插件接口返回 404 并触发状态未确认提示。已在明确的本机 `lele_dev` 开发库执行插件表增量初始化并重启 18787/18788 服务；对比原有 24 张业务表的逐行内容摘要一致。当前用户浏览器中的提示和接口错误已消失，未上架任何插件时显示正常空列表。

最终代码质量审查的三项补充修正已通过 24 项定向测试：候选健康状态退化会拒绝激活；只修改插件资料不再取消有效执行；时间配置统一支持 `HH:MM[:SS]` 并保留秒数。管理员上下架与范围收回的撤销效果继续有效。
