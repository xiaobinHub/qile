## 当前交付范围

已接通直接登录及服务端加密 Token、唯一有效一对一合约自动关联、教师/档期与预约查询、教师收藏、持久草稿、连续单/多课时预约、结果核对、两步取消、学生 PDF 和教师视频。前端包含教师约课工作台及独立课程月历，切换主应用页面保留插件实例和状态；切换儿童、停用或卸载才销毁相应实例。

预约前更换课件只修改草稿；预览直接使用授权草稿中的学员 PDF，不调用扣次接口。原生多课时预约按 App 的 CSV 协议一次派发，不拆成多次预约。

批量顺延、预约后更换课件及 PC 原生上课/回放/预习/作业协议未交付；学习动作提供美森 App 操作说明。多合约选择未交付，多个有效合约会明确报错。真实预约/取消写入闭环、生产迁移/回退演练及物理 iPad 主屏幕模式验收仍待完成，隔离回归通过不能代替这些验收。
