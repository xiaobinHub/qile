# 美森教师档案与筛选优化

按用户浏览器标注直接修改现有插件：移除档案课时时长和复制按钮，嵌入介绍视频；复用共享DatePicker，时段面板支持多选。

- 前端沿用现有入口，不更改主应用页面或共享日期组件。时段以数组存储、逗号拼接到已核验的查询接口。

- 视频票据校验主应用登录、儿童访问权限、插件可用状态、发布epoch、安装generation、账号bindingRevision和凭据revision；仅允许清单内已核验的两个HTTPS域名，禁重定向、限大小，不发送Bearer到CDN。
- 单元测试覆盖票据权限、过期/换绑/版本变化、范围请求和资源关闭；浏览器验证日期组件、多时段查询、原生视频真实播放及拖动、两个字段移除。
