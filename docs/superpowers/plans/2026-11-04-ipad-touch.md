# iPad 触控修复计划

**目标：** 主屏幕 Web App 内的老师全屏列表、侧边列表、预约/课件列表和 PDF 能独立触控滚动；普通页面、弹窗、日历拖动继续可用。

**方案：** 对声明独立视口的工作区锁定文档滚动，统一原生滚动边界与可收缩布局；弹层跟随可见视口。使用现有 PDF.js 依赖和同源模块 worker，把 PDF 连续页面渲染在独立滚动区域，按需渲染/释放画布，提供缩放和失败重试。

- [x] 复现：Chromium 原生触摸手势检查老师列表及滚动边界；WebKit 检查 iPad 横竖屏布局。记录物理 iPad/PWA 无法自动等价模拟的限制。
- [x] 修复：共享 ScrollArea、声明独立视口的页面、插件弹层的滚动和可见高度。
- [x] PDF：替换课件 iframe，支持连续浏览、横向查看放大页面、关闭清理及加载失败重试；worker 保持同源并通过现有插件资源校验。
- [x] 回归：增加真实触摸手势回归，覆盖手势起点在卡片/按钮上、滚动边界、弹层列表、PDF 多页/缩放/失败、横竖屏与关闭恢复。
- [x] 检查：类型、构建、插件功能回归、主应用现有交互回归。测试数据使用隔离样例，临时证据放在系统临时目录。

工作区原有未提交改动保留；本次不部署生产，不操作真实预约。

- `node tests/browser/mison_frontend_acceptance.cjs`：原插件完整功能回归通过。
- 家长端/管理端类型与构建、领域回归、字体/目录检查、11 项插件打包与目录单元测试通过；最终插件可打包，PDF worker 和分包保持同源相对路径。
- 本次改动的格式及 `git diff --check` 通过。全量格式检查仍报告 App.tsx、features/ui.tsx、plugins/store.ts 三处本次未修改文件的原有格式问题。

- 真机 iPad 主屏幕模式的系统回弹、真实键盘与恢复前台仍需设备验收。Chromium 原生手势通过不等同于物理 iPad 复现；现有桌面引擎未重现用户报告的特定系统回弹，修复针对滚动所有权与嵌入 PDF 两条路径。
