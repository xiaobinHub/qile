# 账号头像与家庭角色联动

用户本轮要求取代此前“头像与角色独立变更”的设计。

- [x] 更换头像时使用同一 SQL 同时更新 avatar_id 与 family_role；仍仅可修改本人，不改变权限 role。
- [x] 对所有读取接口以当前头像决定家庭角色，兼容旧账号的 NULL 或历史不一致关系；旧记录在下一次保存头像时持久化同步，不批量改写用户资料。
- [x] 账号 ID 下显示角色标签；更换头像弹窗说明同步变更角色。
- [x] 家庭成员和待确认成员 ID 下增加角色一行；头像放大为 64×64，保留圆角裁切与内边距，有效期缩进同步为 72px。
- [x] 验证事务持久化、账号隔离、昵称不受影响、刷新及失败重试、成员卡片等高、有效期对齐与响应式显示。

仅运行本地开发环境，不发布生产。数据库结构不变，无需升级。

验证结果：后端 129 项测试通过；浏览器 41 个场景通过，100 个无障碍状态零问题、页面错误为 0。管理端及家长端构建、格式检查和 git diff --check 通过。真实开发页面只做读取预览，未替用户保存头像或修改资料。
