# 账号家庭角色 Implementation Plan

**Goal:** 管理端开通账号时，在昵称下以头像加角色名选择爸爸、妈妈、爷爷或奶奶，持久记录账号与儿童的关系。

**Architecture:** 新增 users.family_role 可空白名单字段，独立于权限 role 和可更换的 avatar_id。新开通账号默认爸爸，初始头像与所选角色匹配；旧账号保持关系未知。管理端通过鉴权接口读取现有私有 OSS 头像临时链接。

**Tech Stack:** FastAPI、PostgreSQL、React、共享 Dialog 组件。

- [x] 新增 v5→v6 增量迁移，不修改业务记录 v4 映射或历史 SQL。验证旧库升级、白名单、创建权限和持久化。
- [x] 后端创建支持 familyRole，兼容既有创建请求；返回关系和头像字段；提供管理端四头像目录。
- [x] 新建独立角色选项组件；昵称下单选头像卡片，默认爸爸，取消不创建、失败保留选择，窄屏可用。
- [x] 构建与隔离库测试；开发库备份并核对原数据后升级；仅启用本地服务。
- [x] 在实际浏览器验证管理端 OSS 加载及弹窗布局，不创建真实测试账号。
