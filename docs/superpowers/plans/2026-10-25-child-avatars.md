# 儿童头像接入

已确认需求：20 张黏土头像缩小到 500×500，保留透明通道，上传现有私有 OSS；默认 boy-04。儿童管理头像点击打开分组选择弹窗，选中后保存，管理员可修改。沿用现有权限、服务端存储及标准弹窗。

- [x] 生成 500px 衍生素材并上传独立版本 OSS 目录，逐一验证内容哈希；不修改桶权限。
- [x] 服务端提供带时效签名的头像目录链接；PATCH 验证头像 ID 并保存到儿童 settings，列表和 context 返回该 ID；不改数据库结构。
- [x] 复用头像组件到儿童管理、顶部及孩子切换卡片；新增分组选择弹窗，保存失败保留选择，取消不提交。
- [x] 验证真实隔离测试库中的持久化、权限、非法 ID、取消/失败重试、键盘/响应式布局，运行构建与相关回归。

浏览器验证使用现有 Playwright 测试设施：本会话没有 Browser 插件及 browser skill。

## 验证结果

20 张 500×500 RGBA PNG 上传并回读哈希核验，20 个真实 OSS 签名链接均成功读取。39 项后端测试通过。隔离浏览器测试覆盖分组 20 项、默认 boy-04、取消不提交、保存失败保留选中项、重试与刷新持久化，以及 1626/820/390px 布局；15 个无障碍状态零问题、无页面异常。构建、格式、字号与目录检查通过。重启开发端 18787/18788；当前用户浏览器只读确认 20/20 图片直接从真实 OSS 加载成功。没有进行生产发布。

OSS 对象前缀为配置中的 prefix + `/avatars/clay-500-v1/`。生产发布前需将相同 20 张素材上传到生产配置的对应前缀，保持私有 ACL；不要只发布代码。头像链接由 `/api/child-avatars` 每次签发，有效期 3600 秒，前端在到期前刷新。数据库仅保存 avatarId，旧儿童未设置时显示 boy-04，无需数据库迁移。
