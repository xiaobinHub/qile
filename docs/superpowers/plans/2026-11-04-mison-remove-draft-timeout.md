# 美森预约草稿取消固定有效期

**Goal:** 取消插件自行添加的30分钟预约草稿有效期，兼容已经保存的旧草稿。

**Architecture:** 新草稿的 `expiresAt` 为 `null`，数据库记录不设 TTL。Bridge 的私有读取增加默认关闭的 `includeExpired` 布尔选项，保持儿童、插件、权限及生命周期校验；只有美森草稿读取显式使用它兼容旧数据。读取旧草稿时忽略旧时间字段，后续编辑时以 CAS 保存为无 TTL 记录。账号范围、修订、提交锁、上游真实档期和课件校验保持原有行为。

**Tech Stack:** Python、PostgreSQL、TypeScript，现有插件开发 worker。
