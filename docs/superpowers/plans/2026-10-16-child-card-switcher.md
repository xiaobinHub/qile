# 孩子卡牌切换 Implementation Plan

**Goal:** 将普通白色弹窗改为独立的孩子卡牌，继续只用于切换已有权限的孩子。

**Architecture:** 保留原生 dialog 的焦点约束、Escape、会话失效及业务切换逻辑。外层视觉透明，不使用传统弹窗头部和分隔栏；孩子使用竖向卡牌、大头像、昵称、管理身份和当前标记。桌面并排、手机横向滑动，单张卡牌居中。仅改本地前端，不新增邀请或创建入口。

**Tech Stack:** 原生 HTML/CSS/JS、现有隔离 Playwright 回归。

回滚基线：`c67ce49`。不改业务数据结构、服务端权限或部署。

- [x] `web/parent.html`：透明切换层、独立标题与关闭按钮、卡牌配色和响应式横向布局；减少动态效果偏好下禁用位移动画。
- [x] `web/parent.js`：生成竖向卡牌、当前卡牌标记、卡牌区域内方向键/Home/End 导航，打开时让当前卡牌可见；点击背景关闭。
- [x] `scripts/children_dialog_smoke.cjs`：保留切换、权限、旧响应和失败刷新验证，补充单卡、桌面并排、手机横向滚动与键盘焦点检查，不向实际孩子写测试数据。
