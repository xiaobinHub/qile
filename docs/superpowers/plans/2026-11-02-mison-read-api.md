# 美森约课查询接口接入

目标：在现有插件与现有登录会话上完成教师查询、筛选、档期、我的预约三状态的真实只读接入；不调用预约、取消、换课件或登录接口。

1. 核验 myOneToOneList 与 myCourseList 关联。合约 id=课程 liveid，合约 courseid=课程 classid，合约 gradeid=课程 new_liveid；仅自动选唯一有效合约，拒绝猜测。
2. 新增 upstream.py（固定查询白名单、总超时、双域错误映射）、read_api.py（DTO、分页、日期与占用映射）、read_store.py（带 childId、bindingRevision、credentialId 和合约条件的worker内有界TTL缓存/游标，重启后明确失效）、images.py（无凭据、限域、限大小的头像读取）。查询不会向外发送写操作。
3. routes.py 分发已有前端 GET 合同；bootstrap 回填合约和预约中计数；登录状态失效经服务端标记而不触发主应用401或自动登录。
4. 教师搜索按 tid 去重普通池与智能池；收藏交叉日期/时段持续扫描到终止；预约按实际元信息扫描、排序并分页。游标绑定查询和会话，过期明确重查。
5. 头像通过已有插件JSON API按需读取为小图片数据URI，复用现有CSP允许的data图片，无主应用修改。未接入的写入与课堂等入口不伪装可用。
6. 注入上游响应验证ID区分、分页、占用、过期、授权与错误。使用当前Token真实只读验收，核对没有登录/写接口。构建1.0.7并通过原部署流程更新本机，保留配置与Token。
