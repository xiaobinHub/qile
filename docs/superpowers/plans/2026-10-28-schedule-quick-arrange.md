# 日程快捷编排 Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the independent backend task; integrate and validate the feature in this session.

**Goal:** 在现有月历中拖入常用任务、跨日期移动任务、拖至删除区删除，保存整体提交，取消退出并丢弃草稿。

**Architecture:** 复用现有 MonthCalendar、顶部栏和日期导航；编辑时以本地草稿投影覆盖任务列表。一次 `task.batch` 操作仅接受任务创建及 scope=only 的编辑/删除，沿用修订号、权限、幂等和数据库事务。已完成任务冻结，重复任务只调整本次，新增任务不重复。

**Tech Stack:** React / TypeScript、现有共享 UI、Pointer Events（鼠标与触屏）、Python 业务操作、PostgreSQL、Playwright。

## 设计边界（用户已确认）

- 现有顶部栏、月份标题、月份导航、月周切换、日期和日历表格直接复用；仅编辑状态改变任务前导控件。
- 月视图新增“快捷编辑”入口；进入后隐藏月历操作栏，上方横排无插画图标的常用任务卡片；右上角可直接添加常用任务。
- 编辑状态下任务前导控件改为六点拖动手柄；已完成任务不可移动/删除，手柄保持禁用及对应控件说明，不展示常驻文字提醒。
- 拖入日期新增，日期间拖放仅调整日期且保留时段；仅明确释放到删除区才删除。
- 日期悬停反馈为主题淡黄色；无拖拽轨迹线。
- 日程提交操作仅“保存”“取消”，左下角为垃圾桶投放区。日程草稿保存前不写服务端，取消退出且丢弃草稿。
- 底栏左侧垃圾桶的辅助名称为“任务拖到此处可删除”；不另占一栏，不提供撤销按钮。
- 保存失败保留草稿；网络结果未确认沿用原操作编号重试，避免重复创建；数据版本变化则禁止覆盖。
- 编辑中通过现有 runtime.setEditing 阻止自动数据刷新；离开页面/孩子或切换周视图时需明确放弃草稿，保存中不能离开。
- 桌面与 iPad 拖放可用；窄屏保留七列日历与横向常用任务条，拖动手柄不劫持日历正常滚动。
