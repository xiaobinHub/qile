# Plugin Detail Cards Implementation Plan

**Goal:** 插件详情分为名称/状态头部及详情、发布范围、版本与部署记录三张独立卡片，复用儿童管理页面的卡片分隔方式。

**Architecture:** 保留 PluginDetail 的资格、修订、范围确认及请求不确定性处理；资料表单移动到共享 Dialog，页面只读展示。详情容器透明、无外层边框，由三张白色 Card 独立承载内容；活动版本信息移到部署记录卡片。

- [x] 重排三卡片与顶部状态/发布动作，取消详情外层白色面板。
- [x] 资料编辑改为弹窗，保留字段、校验、并发防护和失败恢复；成功保存后更新展示并关闭。
- [x] 桌面/平板/窄屏浏览器验证布局、真实保存/取消/冲突及发布范围和记录入口，执行构建和定向检查。

追加反馈已完成：顶部名称/状态/操作使用独立白卡片；移除常驻重新载入和记录刷新按钮；移除资料弹窗的图标选择（不提交 icon 字段）；排序按数值从大到小同步到后端、后台列表、家长应用列表和顶部导航。仅状态冲突/结果不确定时提供核对入口。

验证：9 项后端定向测试和 17 项真实浏览器检查通过。覆盖 1280×960、820×1180、390×844、667×375 touch；编辑取消/保存、图标保留、409 冲突、响应丢失恢复、发布范围、上/下架确认、部署记录读取和后台/家长端排序；页面异常为 0。测试使用 lele_test_demo_plugins 和独立端口，证据保存在 /tmp/lele-plugin-detail-feedback-qa。

插件列表追加反馈：按列表容器宽度使用桌面三列、平板两列、手机一列；紧凑卡片、标题同行彩色状态标签、右侧黄色小尺寸管理按钮（触屏保留44px点击高度）；移除常驻刷新按钮，保留自动更新及失败重试；搜索框与账号管理统一为300px。构建/字体检查及5项浏览器检查通过（1626×984、1024×1180、390×844），覆盖真实搜索、发布状态筛选和详情往返，页面异常为0。使用独立测试库lele_test_demo_plugins，证据位于/tmp/lele-plugin-catalog-qa。
