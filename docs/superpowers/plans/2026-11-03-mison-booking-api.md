# 美森预约与课件 API 接入实施计划

> **For agentic workers:** 按本文任务顺序实施，已有页面设计已由用户确认；直接完成当前插件并在本地发布。

**Goal:** 打通选时段→推荐/选择/预览课件→确认预约→核对结果→我的预约，补齐取消与学生资料入口。

**Architecture:** 保留shadcn前端、既有私有Token与动态合约关联。草稿用私有记录CAS持久化；所有上游写入先落操作日志并获取同美森账号数据库租约，发送前持久标记dispatching。写入超时只读取结果，不重发。资源复用现有同源受控代理，增添PDF支持。

**Tech Stack:** React19/shared shadcn、独立Python标准库worker、现有PostgreSQL Bridge和媒体代理。
