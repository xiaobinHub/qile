# 账号管理合并与常用任务编辑

用户已明确要求合并账号昵称/密码页面并调整常用任务表单。采用现有账号资料 PATCH、密码修改及 TimePicker 控件。

- [x] 账号导航合并为“账号管理”；顶部资料卡展示通用头像、登录 ID、昵称、编辑按钮，昵称弹窗调用原 API（最多 40 字）；下方独立密码卡沿用密码表单及登出行为。
- [x] 常用任务的结束时间改为持续时长，开始时间变化时保留时长（接近午夜时限制到当天）；不允许 0 分钟或跨日；持久化仍为 startTime/endTime。
- [x] 任务类型和积分放在同一行，窄屏也保证控件可用。
- [x] 更新受影响导航测试；验证昵称取消/失败/成功、密码表单与权限、时长换算/编辑回显/午夜/保存结果及桌面、iPad、手机布局。构建与隔离浏览器回归。

不修改正式账号、密码或业务数据，不发布生产。

家长端构建、格式、字号、目录检查及 domain/runtime 测试通过。完整隔离浏览器回归通过 39 个场景，91 个无障碍状态零违规、零页面异常。验证昵称取消、失败保留/重试、成功更新与焦点返回；密码卡片的显示/输入及原退出行为；持续时长在 1305/820/390px 下同排布局、开始时间联动、持久化/编辑回显、零时长拦截和午夜限制。已检查桌面和手机截图。
