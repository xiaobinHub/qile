# 家长端设置分栏设计

状态：用户于 2026-10-19 确认直接实施。改造前版本：`2189956`。

## 范围与布局

本次只开发、调试本地测试环境，不发布生产。家长端设置采用左侧分组导航、右侧单一功能内容区。沿用现有绿色、细边框、圆角和留白；窄屏将导航放在内容上方，避免横向溢出。默认选择孩子昵称，重新渲染时保留当前设置项，切换孩子时重置。

| 分类 | 独立入口 |
| --- | --- |
| 孩子管理 | 孩子昵称、邀请家人、我的邀请 |
| 任务设置 | 常用任务配置、任务类型配置、数据备份 |
| 账号管理 | 修改账号昵称、修改密码、退出登录 |

采用直接展示所选功能的分栏方案。任务配置列表常驻右侧，新增、编辑保留现有弹窗。相较入口列表再开整页或弹窗，减少浏览层级，也维持原有编辑器。

## 孩子管理

孩子昵称页：展示当前孩子、角色和昵称表单。仅未归档孩子的负责人可以保存；共同管理家长可以查看。归档、恢复或退出管理收在页面底部的折叠管理区，执行前确认。

邀请家人页：负责人填写已开通账号的登录名发送邀请，下方分别展示共同管理成员和已发邀请。共同管理家长可查看成员，无发送、移除、转让或撤销权限。转让与移除收在次要操作区并确认；归档孩子禁止写操作。邀请状态转换为中文，空列表和请求失败有明确反馈。

我的邀请页：展示当前账号收到的有效邀请，包含孩子昵称和到期时间，分别提供接受和拒绝。处理后刷新邀请与孩子列表；接受后提供进入孩子的按钮，不自动跳离当前页面。已处理或过期的邀请由服务端拒绝，显示错误并允许刷新。无孩子的账号也能从账号页进入设置处理邀请。

孩子卡牌切换器继续只用于切换孩子，不加入创建或邀请入口。现有初始账号的创建孩子和无孩子引导保留。

## 任务设置

常用任务配置、任务类型配置分别在右侧展示现有列表，使用已有新增、编辑、删除、排序及校验逻辑。归档孩子的配置只读。数据备份按用户补充确认保留在任务设置底部；可导出当前孩子备份，只有未归档孩子负责人可导入恢复。

移除家长设置中的访问地址入口，不展示旧局域网共享入口或口令功能。危险清空数据入口继续隐藏。

## 账号管理

昵称与密码分别使用独立表单。登录名可查看但不可编辑，资料接口禁止改登录名，后台共用资料表单同步只读。管理员开通账号时仍指定初始登录名。

修改昵称只提交 nickname。修改密码继续校验当前密码、新密码、重复密码；新密码至少六位并包含英文字母和数字，成功后注销已有会话并回到登录。首次强制改密仍不能绕过。

退出登录是带确认的操作，不渲染无意义的空页面；取消确认不调用接口。

## 技术边界与状态

设置界面拆为独立的家长端脚本和样式，通过显式依赖调用原有 API、命令和编辑器。静态资源通过精确白名单开放。保持 cookie、Origin、CSRF 和孩子授权检查。

导航切换和孩子切换后，旧请求不能更新新面板或泄露旧孩子资料。提交期间禁用重复操作，错误留在相关表单；读取失败有重试入口。孩子昵称更新后同步标题、头像与当前业务设置，不丢失日历上下文。

## 验收

在独立 lele_test 数据库验证昵称保存、只读登录名、账号密码、发送/撤销/接受/拒绝邀请、成员权限、归档只读、任务配置和备份权限。浏览器验证分栏与窄屏布局、切换后的过期响应、退出取消、首次强制改密，并运行已有业务回归。生产和本地开发业务数据不作为写入测试对象。


## 同日浏览器批注修订

用户明确要求首页直接进入日历任务页，并移除旧“我的孩子”独立页面。因此首页按当前账号上次选择的未归档孩子进入日历，无偏好时选择首个未归档孩子，仅有归档孩子时可只读查看。偏好只保存孩子 ID，并按账号分别保存；仍需实时校验授权列表，失效或被移除时不使用旧 ID。直接访问孩子链接仍以该链接为准。没有任何孩子时展示日历空状态，创建引导放在孩子昵称的空状态，收到的邀请仍从设置中处理，不生成默认业务数据。

设置详情区移除重复的一级分类文案，左侧分类导航保留；设置标题右侧的孩子信息和“我的孩子”入口移除，切换只使用页面最右上角原有卡牌入口。

已发邀请增加数据库真实 created_at 对应的 createdAt 字段，界面显示发出日期和时间。撤销邀请从查询和显示列表中排除，但数据库行及审计不删除。其他状态继续保留。

验证增加根路径多孩子日历、最近选择、无权限偏好回退、无孩子日历空状态、邀请真实发出时间、撤销后列表消失，以及移除入口后日历与设置仍可导航。


## 未绑定孩子的初始页（用户进一步修订）

未绑定任何孩子的账号，登录后使用独立初始引导页，页面可直接填写昵称创建孩子，右侧显示本人收到的有效邀请并可接受或拒绝。没有邀请时提示家人使用当前账号登录名发送邀请；读取失败显示重试，不伪装为空列表。创建或接受邀请后直接进入该孩子的日历，拒绝后停留初始页。

此状态顶部主导航只显示设置，日历与积分商城不出现；设置只显示账号管理下的昵称、密码、退出，隐藏整个孩子管理和任务设置分组。默认进入账号昵称，设置内容区可返回开始页，不增加新的顶部 Tab。已绑定孩子的账号维持完整导航和现有孩子卡牌切换。

初始页与设置之间切换会使旧请求失效，过期邀请响应不能重新显示在账号设置中。所有测试继续使用独立测试库，本机开发业务数据不用于测试写入。

## 首次及重置后的密码设置（用户批注修订）

强制设置密码页面移除“日历首页”和“账号管理”入口，改为居中的独立卡片，包含新密码、再次输入新密码、密码规则、保存按钮和底部退出登录。沿用绿色、细边框及留白，适配桌面和手机。此页面不再要求填写当前密码，普通账号在设置中主动修改密码仍须验证当前密码。

服务端依据已认证账号数据库中的 must_change_password 状态允许强制设置时只提交 newPassword，不接受客户端标记来绕过当前密码校验。保留 Origin、CSRF、六位字母数字规则、禁止新旧密码相同及成功后撤销所有会话的行为。首次设置和管理员重置后均适用。

后续五处批注细化：强制设置卡片底部不显示账号名称，退出登录居中；顶部说明去掉强制换行；密码帮助文案统一为“密码至少 6 位，同时包含数字和字母”；强制设置页面移除保存后重新登录的提示。密码校验和保存后的重新登录行为保持原样。

密码输入框右侧提供小眼睛按钮，首次设置的两个密码框、日常改密的三个密码框分别独立切换显示和隐藏，默认隐藏，不改变输入内容或触发表单提交。按钮支持键盘操作并同步可读标签与按下状态。家长端退出登录统一使用页面内确认弹窗，提供取消和退出，默认聚焦取消；Esc 取消、关闭后恢复焦点，只有确认才提交退出请求。弹窗在账号失效或跨页退出时随上下文一并关闭。

按用户进一步要求，强制密码设置卡片改为 React 与现有 shadcn/ui Card、CardHeader、CardTitle、CardDescription、CardContent、CardFooter、Input、Label、Button 实现。现有 UI 样式和交互完全保留，组件样式使用原家长端类覆盖，不向其他页面注入全局 Tailwind reset。仅独立挂载此页，清理账号上下文时先卸载 React；业务接口、普通设置页和退出确认继续复用现有逻辑。
