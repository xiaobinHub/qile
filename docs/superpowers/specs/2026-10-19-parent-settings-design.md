# 家长端设置分栏设计

状态：用户于 2026-10-19 确认直接实施。改造前版本：`2189956`。

## 范围与布局

本次只开发、调试本地测试环境，不发布生产。家长端设置采用左侧分组导航、右侧单一功能内容区。沿用现有绿色、细边框、圆角和留白；窄屏将导航放在内容上方，避免横向溢出。默认选择孩子昵称，重新渲染时保留当前设置项，切换孩子时重置。

| 分类 | 独立入口 |
| --- | --- |
| 孩子管理 | 孩子昵称、邀请家人、我的邀请 |
| 任务设置 | 常用任务配置、任务类型配置、数据备份 |
| 账号管理 | 修改账号昵称、修改密码、退出登录 |

采用直接展示所选功能的分栏方案。任务配置列表常驻右侧，新增、编辑保留现有弹窗。相较入口列表再开整页或弹窗，减少浏览层级，也维持原有编辑器。

## 孩子管理

孩子昵称页：展示当前孩子、角色和昵称表单。仅未归档孩子的负责人可以保存；共同管理家长可以查看。归档、恢复或退出管理收在页面底部的折叠管理区，执行前确认。

邀请家人页：负责人填写已开通账号的登录名发送邀请，下方分别展示共同管理成员和已发邀请。共同管理家长可查看成员，无发送、移除、转让或撤销权限。转让与移除收在次要操作区并确认；归档孩子禁止写操作。邀请状态转换为中文，空列表和请求失败有明确反馈。

我的邀请页：展示当前账号收到的有效邀请，包含孩子昵称和到期时间，分别提供接受和拒绝。处理后刷新邀请与孩子列表；接受后提供进入孩子的按钮，不自动跳离当前页面。已处理或过期的邀请由服务端拒绝，显示错误并允许刷新。无孩子的账号也能从账号页进入设置处理邀请。

孩子卡牌切换器继续只用于切换孩子，不加入创建或邀请入口。现有初始账号的创建孩子和无孩子引导保留。

## 任务设置

常用任务配置、任务类型配置分别在右侧展示现有列表，使用已有新增、编辑、删除、排序及校验逻辑。归档孩子的配置只读。数据备份按用户补充确认保留在任务设置底部；可导出当前孩子备份，只有未归档孩子负责人可导入恢复。

移除家长设置中的访问地址入口，不展示旧局域网共享入口或口令功能。危险清空数据入口继续隐藏。

## 账号管理

昵称与密码分别使用独立表单。登录名可查看但不可编辑，资料接口禁止改登录名，后台共用资料表单同步只读。管理员开通账号时仍指定初始登录名。

修改昵称只提交 nickname。修改密码继续校验当前密码、新密码、重复密码；新密码至少六位并包含英文字母和数字，成功后注销已有会话并回到登录。首次强制改密仍不能绕过。

退出登录是带确认的操作，不渲染无意义的空页面；取消确认不调用接口。

## 技术边界与状态

设置界面拆为独立的家长端脚本和样式，通过显式依赖调用原有 API、命令和编辑器。静态资源通过精确白名单开放。保持 cookie、Origin、CSRF 和孩子授权检查。

导航切换和孩子切换后，旧请求不能更新新面板或泄露旧孩子资料。提交期间禁用重复操作，错误留在相关表单；读取失败有重试入口。孩子昵称更新后同步标题、头像与当前业务设置，不丢失日历上下文。

## 验收

在独立 lele_test 数据库验证昵称保存、只读登录名、账号密码、发送/撤销/接受/拒绝邀请、成员权限、归档只读、任务配置和备份权限。浏览器验证分栏与窄屏布局、切换后的过期响应、退出取消、首次强制改密，并运行已有业务回归。生产和本地开发业务数据不作为写入测试对象。
