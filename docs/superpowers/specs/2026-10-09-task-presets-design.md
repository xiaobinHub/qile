# 常用任务配置

用户批准：设置管理常用任务；任务内容输入框融合自由输入和下拉选择，不新增独立选择入口。

## 交互

- 配置名称（1–80 字）、任务类型（现有可用类型）、开始/结束时间（结束晚于开始）、奖励积分（0–9999 整数），允许同名；删除需确认。
- 新建任务时点击输入框展示匹配项，输入名称实时筛选；箭头展示全部或收起。自动聚焦不展开。
- 下拉项显示名称、时间和积分，选择后复制名称、类型、时间、积分，保留日期、备注和重复规则。之后可以自由修改。
- 支持上下键、Enter、Esc、Tab 和中文输入法；Enter 在候选列表展开时不提交任务。编辑已有任务不显示下拉。
- 列表锚定输入框，适配滚动与窄屏，并与日期/时间浮层互斥。

## 保存

- 数据增加 taskPresets，每项 id/title/categoryId/startTime/endTime/points；沿用 schemaVersion=2 和完整数据接口。
- 旧数据仅在缺少字段时补充空列表；错误列表明确报错。
- 配置参与现有按 id 的跨设备合并、自动备份、导出导入。已创建任务与配置独立。
- 保存期间禁用按钮；失败恢复保存前状态并保留填写内容。

## 验证

使用临时目录与隔离端口，不对正式服务写入测试数据。覆盖管理、填充、输入法、键盘、保存失败、设备冲突、备份恢复和窄屏显示，并运行页面自检和服务端测试。

## 类型与卡片列表迭代

- 常用配置列表改为独立卡片，展示名称、类型色标、时间、积分以及编辑/删除按钮；添加按钮移至标题栏，删除原说明文案。
- 新增/编辑配置必须选择现有可用类型。旧配置缺少类型时保持兼容，不随意分配；使用时保留任务表单当前类型，编辑配置后补齐。
- 仅被常用配置引用的类型删除时也保留关联并停用。使用停用类型的配置会要求重选类型，防止保存无效任务；历史任务不联动改变。
- 类型随配置保存、备份与现有合并流程持久化；不存在或格式错误的类型引用由前后端拒绝。
- 验证：服务端 11/11，页面自检 47/47；隔离 Chromium 实际验证类型增改、快捷填充、类型停用与旧配置升级，1280×900 和 390×844 卡片截图完成视觉检查。
