# 完整接入 Demo 插件

用户要求提供一个页面型和一个无页面型 Demo，覆盖当前插件协议的各种功能。使用独立 ID `demo-page`、`demo-service`，版本均从 1.0.0 开始；保留现有最小示例和其升级验收。

## 页面型 Demo

独立 ESM/CSS 和 Python worker。页面包含共享记录的分页读取、创建、修订号编辑和归档（不提供平台删除）、同 operationId 重试、冲突后重新核对、服务端探测、受控错误、慢请求、通知、核心导航和运行信息。退出、切换儿童及停用时清理定时器、监听和异步渲染。

配置使用平台支持的字符串、整数、小数、布尔、枚举、多选、日期、日期时间、邮箱和网址格式，以及分组、默认值和边界校验。运行信息只回传插件自身当前儿童上下文和配置，不返回签名凭证。默认每 60 秒记录后台心跳，订阅 task.completed；页面可读取本插件 activity 集合查看证据。

## 无页面型 Demo

`frontend=null`，只有平台配置弹窗，没有顶部入口。包含共享消息、记录通道、每日时间/时区、星期多选、批量记录数量、小数权重、心跳/事件开关和默认关闭的失败模拟。提供 60 秒心跳、配置驱动的每日任务、task.completed 事件、手动探测 API，以及 executions 集合持久化效果。事件与任务按 occurrenceKey 去重；失败交由平台重试；停用后资格围栏拒绝效果。

## 共用边界和验收

全部四项当前协议能力均在清单中声明；包内提供 PNG 图标、名称、简介、操作说明。只使用当前儿童/插件命名空间，不触达真实外部消息服务。后台没有自建永久业务定时器。

交付独立构建包、配置/处理函数单测、真实 worker/网关/任务/事件/幂等/隔离/撤销验收及页面浏览器验收。测试只写入 lele_test* 和 data/testing。完成后可在本机开发环境登记为待发布，交由管理员选择发布范围；不自动替儿童安装或启用。提供逐项能力矩阵及复测步骤，明确协议尚不支持任意数据迁移、真实外部通知凭据和平台删除。
