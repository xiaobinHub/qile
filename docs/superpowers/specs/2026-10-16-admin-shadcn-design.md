# 管理后台 shadcn/ui 重构设计

状态：用户已确认按推荐布局实施（2026-10-16）。改造前代码版本：`79d7757`。

## 目标与范围

重构本机 `http://127.0.0.1:18788/` 管理后台的登录、账号管理、账号开通、密码重置与我的账号页面。采用实际 shadcn/ui 组件与 React，不仅替换 CSS。家长端、数据库结构、接口和权限保持现有行为；本次不发布阿里云。

## 推荐布局

采用固定侧栏与独立内容区。桌面侧栏约 216px，包含品牌、账号管理、我的账号；底部展示当前管理员及退出入口。顶部展示当前位置与页面标题，主内容使用统一的间距、字号和细边框。

账号管理默认展示账号列表。标题右侧是“开通账号”主按钮；列表上方集中放置搜索、状态筛选与刷新。简洁的概览展示真实账号数量与待改密数量，不增加暂无功能的导航、图表或占位模块。

账号列表区分昵称、登录名、账号类型、账号状态和操作。已停用优先显示“已停用”，否则需要改密的账号显示“待改密”，其余显示“已启用”；筛选与统计使用相同定义。管理员账号继续没有家长账号的停用与重置操作。

“开通账号”使用 Dialog，依次填写登录名、昵称、初始密码，并显示现有字段规则。提交期间防止重复操作，错误留在表单中，成功后关闭并更新列表。密码至少 6 位且同时包含英文字母和数字。

行操作菜单提供重置密码、停用或启用。密码重置使用独立 Dialog；停用或启用使用 AlertDialog，明确显示目标账号与现有影响说明。取消不发送写入请求。

“我的账号”使用独立页面，分为基本资料和密码设置两个卡片，避免多种任务混排。首次强制改密时只允许完成密码设置；修改登录名时继续要求当前密码；改密后继续撤销会话并返回登录。

## 视觉与响应式

使用 shadcn/ui 的浅色中性色、白色卡片、细边框、适量圆角与清晰的文字层级，绿色用于品牌和主要操作。统一使用 Lucide 图标。避免大面积装饰和过大的表单空白。

在用户当前 1059×954 窗口下完整展示导航、页面标题与主要表格；窄屏使用可收起导航，搜索和主按钮能够换行，弹窗适配屏幕高度，页面不产生横向溢出。表格必要时仅在自身区域滚动。

交互使用真实按钮和字段标签，图标按钮提供可访问名称。Dialog/AlertDialog 支持键盘、焦点约束、关闭后回到触发点；错误和成功提示可被辅助技术读取。

## 接入与状态

管理后台新增独立 React + TypeScript + Vite 构建入口，按官方方式接入 Tailwind 和 shadcn/ui。组件源码、构建配置和锁定依赖纳入版本管理。构建结果继续由现有 Python 服务在同源提供，不依赖 CDN，不要求为访问后台额外启动 Node 服务。

静态资源保持明确的后台专用目录和路径校验，家长端不暴露后台源码、配置文件或任意文件。新增构建步骤写入本地开发及后续生产准备说明。

请求继续使用现有 HttpOnly Cookie、同源 Origin 校验及 CSRF Token。切换页面、退出或会话失效时清理敏感状态；旧请求不能覆盖新的页面或会话。账号列表提供加载、失败重试、空列表和无匹配结果状态。

## 备选方案

保留开通表单常驻页面可减少一次点击，但会持续占用空间、削弱账号列表的主次关系，因此推荐按需弹窗。
