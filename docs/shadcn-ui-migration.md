# 前端组件统一与本地验收

日期：2026-10-20 至 2026-10-21。范围：当前家长端和管理后台。分支：`codex/child-accounts`。

## 完成内容

两端统一为 React、TypeScript、Tailwind CSS 和共享 shadcn/ui 组件。家长端只有一个 React 根节点；旧 DOM 渲染、独立 React 挂载桥接和浏览器业务 confirm/alert 已退出当前应用，旧脚本及其过时测试辅助模块已删除。根目录的旧版独立工具与生产固定版本不参与此次迁移。

- `shared-ui/src`：基础控件、绿色主题、密码、日期、日期范围、精确分钟时间输入、表单、空状态、异步确认和通知。两端的 `components.json` 与构建别名均指向这里。
- `parent-ui/src`：账号、无孩子引导、孩子卡牌、连续月历与周历、任务、商城、设置、备份和打印。业务计算独立为 TypeScript 模块，设置不再依赖旧页面回调修改 DOM。
- `admin-ui/src`：保留已确认的管理布局，改用同一组件来源、主题和交互规范。

共享主色为 `#39734F`，普通正文默认 14px、说明不小于 12px，普通控件 40px、触屏主要控件 44px。保留孩子卡牌和 A4 横向打印的专门布局。交互图标使用 Lucide；日期使用本地日期字符串，不转换成 UTC；自定义分钟不被五分钟选项覆盖。

现有业务 API、数据格式、权限和数据库结构不变。家长端产物为 `web/parent-dist`，资源入口 `/parent-assets/`；管理端产物为 `web/admin-dist`，资源入口 `/admin-assets/`。静态资源限制在对应构建目录，源码、配置及 source map 不开放。两端依赖随构建打包，不使用外部 CDN。

## 数据与保存保护

保留修订号、成员版本、操作 ID、服务端业务命令、过期响应隔离、每 30 秒及页面重新聚焦时的权限检查。切换孩子和退出会取消旧请求并清理当前数据、编辑与打印状态；被删除或失去权限的孩子不再显示原数据。

保存结果不明确时保留原操作编号。刷新只读，不自动重新写入，也不丢弃编号；用户可明确选择“重试原操作”，仍使用原编号。确认成功后关闭原表单，避免再次产生新操作。已验证“服务端实际提交成功但响应丢失 → 刷新 → 原编号重试”只产生一条流水。

旧 schemaVersion 1 备份、缺少常用任务/规则版本的旧备份继续按原兼容规则处理；源文件不修改。恢复仅允许当前未归档孩子的管理员，并保留原孩子身份与成员权限。
