# 字体与紧凑布局验收

2026-10-22，开发分支 `codex/child-accounts`。已完成当前 React 家长端、管理端及共用组件的字体规范落地与页面紧凑化。未发布生产环境，未改变业务接口、权限、数据库结构及打印算法。

## 完成结果

- 统一八类字号：12、13、14、15、16、20、22、24px，对应 rem 和固定语义行高；正文、导航、标签、按钮和表格主信息默认 14px，普通说明 13px。
- 页头常规高度 112 → 72px；日历单行工具栏最小高度 98 → 64px，桌面操作按钮 54 → 36px，触控操作至少 44px。
- 商城按视口宽度采用四列 / 三列 / 两列；统一卡片内边距、两行名称空间、积分数字及底部按钮对齐。
- 设置菜单 14px、分组 13px、详情标题 20px；PC / iPad 左栏 208 / 184px，取消固定面板最小高度。管理端表格正文和操作采用同一字体层级。
- 修复全局 h2 覆盖共享弹窗标题的问题；取消设置表单对所有说明段落的笼统覆盖，使辅助说明沿用共享 caption 规范。
- 新增 `check:typography`，防止重新引入任意 px / vw 屏幕字号；字体规范和布局规则见 [统一规范](../字体与响应式规范.md)。
