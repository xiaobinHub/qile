设计范围：成长计划 Web 应用现有时间选择器 Popover，PC 与 iPad 共用。仅设计此组件，不改动任务弹窗的表单布局和业务能力。参考图是隔离测试页面 /tmp/lele-time-picker-20261022/targeted/time-picker-1305.png。

共同要求：Vega 小圆角，Mist 中性色，白色内容表面，黄色 #FACC15 主色与浅黄 #FFF0B3 选中面，深色正文 #1F2933，Inter/PingFang 字体。小时和分钟两个独立竖向滚轮，中间同行为唯一选中值；上下数字沿滚筒弧面缩小、倾斜并逐渐隐去。中心清晰、对齐，触控行高至少44px，不能只把现有平面列表加渐变。小时00–23，分钟00–59，保留逐分钟精度。拖动、滚动后逐格吸附，轻量惯性；选中时间始终可读。允许点击相邻数字、键盘上下键。无输入键盘、无底部说明文案。滚动时不自动关闭，右上角“完成”收起。

参考画布：1305×954，保留现有任务弹窗背景并淡化；时间选择器为焦点，必要时在独立放大组件图中呈现约320×330px自然尺寸。示例17:30，小时依次15、16、17、18、19；分钟依次28、29、30、31、32。标签仅“小时”“分钟”，不出现“24小时制”。不添加其他功能、品牌、设备边框。

独立设计方向：
A 温润白瓷滚筒：两个浅色弧面滚筒藏在同一白色面板，连续浅黄中心选择带，细小阴影与轻微凹槽呈现机械转动质感，最贴近现有页面。
B 精密仪表滚筒：白色外壳内有两个深石墨灰滚筒，选中数字为清晰明亮浅黄，外层少量细刻度。避免花哨霓虹和金属装饰，触控区域足够大。
C 细腻银灰滚筒：同一浅银灰凹槽内并排两个独立滚筒，以两侧黄色定位短线与中心水平槽强调选中行。弱化整块黄色底，突出弧度和数字层级。
