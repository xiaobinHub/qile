## 自动化与人工检查

- 两端 TypeScript 检查、正式构建、源文件格式、diff 空白检查通过。构建仍提示既有家长入口包超过 500kB（约 606kB、gzip 185kB）；这是后续性能优化项，未通过修改阈值隐藏提示。
- `npm run test:domain`：33 个历史行为等值样例，以及未知保存结果、原操作编号重试、跨孩子迟到响应等运行时保护通过。
- 后端独立数据库回归：88 项通过。
- `npm run test:browser`：23 组流程通过，页面 JavaScript 错误为 0。覆盖账号改密、无孩子引导、切换/邀请/成员权限、归档只读、逻辑删除、任务规则和修改范围、完成撤销、礼品图片/兑换/积分、备份恢复、打印、冲突/丢失响应/重复操作/迟到响应及退出清理。
- axe WCAG A/AA 自动检查：15 个状态均为 0 问题，包括卡牌、规则表单错误、设置家人、类型菜单、流水、后台及确认对话框；不以自动扫描替代人工或真机验收。
- PC：1280×720、1280×900、1440×900。iPad Chromium 模拟：820×1180、1180×820、1024×1366、1366×1024。每组均检查弹窗可达、完整设置分栏、日历/流水/后台无页面溢出，并保留截图。
- 额外只读走查保留 69 张截图，含密集日历、长昵称、无图礼品、失败/空态、成员和主屏幕模式模拟。业务写入均拦截。走查初次未登录及错误密码案例的 HTTP 401 为预期结果，未发现页面 JavaScript 异常。
- 使用截图逐页检查 PC/iPad 的层级、间距、文字、卡牌可读性和列表；本目录保留 7 份关键页面前后对比，左为优化前，右为最终视觉效果。
