## 发布边界

正式包必须来自干净的 main 合并提交并附固定标签，逐文件记录 SHA-256；包中不含任何插件源码目录、完整 Demo 发布包、测试数据或私有配置。插件结构通过 `deploy/manage.py upgrade-plugins` 预览目标后显式执行，不执行初始化、历史数据导入或账号重置。

保留当前腾讯云版本及上线前一致性备份；代码回退保留当前数据库和 OSS 增量，不用旧备份覆盖线上数据。阿里云服务本次不更新、不停止。

已知基础设施边界：RDS 沿用原未启用 TLS 的连接配置；腾讯云接入备案审核期间，公网 HTTP 跳转及 HTTP-01 证书续期演练此前受服务商拦截。HTTPS 正常不能替代 HTTP/续期验收，发布后另行记录实测结果。
