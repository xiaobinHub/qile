# 历史程序

此目录仅保留旧单页面、本机 HTTP 服务和旧 RDS 迁移代码，供历史对照及兼容回归。它们不参与当前 FastAPI 服务运行，也不进入发布包。不要将旧版程序连接到新版多孩子数据库。

本地生产启动/停止 `.app`、命令及控制脚本已删除；本地只运行开发和测试。旧生产实施资料位于 `docs/archive/local-production/`，已标记为历史记录。独立旧生产目录及进程没有被本次整理操作。

当前入口：本地 `scripts/dev.py`；阿里云 `deploy/run.py`。历史服务测试保留在 `tests/backend/`，只操作临时目录或明确命名的本机测试数据库。
